# Facebook – Моделиране и анализ на база данни

Факултетен номер: 2401321054

Тема: Facebook

Описание на проекта:

Курсовата работа представя проектиране и реализиране на релационна база данни за социалната мрежа Facebook.

Моделът включва потребители, публикации, коментари, реакции, групи и приятелства между потребители.

Използвани технологии:

- draw.io
- Microsoft SQL Server Express
- SQL Server Management Studio
- Power BI Desktop

Инструкции за инсталация и стартиране:

1. Инсталирайте Microsoft SQL Server Express и SQL Server Management Studio.
2. Създайте база данни FacebookDB.
3. Изпълнете SQL скриптовете за създаване на таблиците и добавяне на примерни данни.
4. Изпълнете скриптовете за съхранената процедура, функцията и тригера.
5. Отворете диаграмите чрез draw.io.
